# WaterFlow

Minimal Flutter water tracker app.

## Status

Portfolio project.

## Stack

- Flutter
- Dart
- Riverpod

## Run locally

1. Clone the repository:
```bash
git clone https://github.com/NataliaAtiukova/WaterFlow.git
cd WaterFlow
```
2. Install dependencies:
```bash
flutter pub get
```
3. Run:
```bash
flutter run
```

## Notes

Main source code is in `lib/`.
